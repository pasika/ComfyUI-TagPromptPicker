## 🌟 English Introduction

**ComfyUI-TagPromptPicker** is a lightweight, intuitive, and efficient custom node designed for ComfyUI. It allows you to easily manage, pick, and organize your text prompt tags locally without relying on external complex software or system dependencies.

### ✨ Key Features
* **Directory Management**: Specify and persist your custom tag folder path (`prompt_dir`) via configuration.
* **Dynamic Tag Loading**: Automatically scans and lists all `.txt` files in the target directory as interactive buttons for one-click prompt injection.
* **Smart Prompt Stitching**: Intelligently handles custom delimiters (e.g., `, `) and automatically trims redundant separators to ensure clean formatting.
* **Built-in Prompt Organizer**: Clean up and deduplicate your prompt tags with a single click.
* **File Management & Saving**: Easily clear text or save the current prompt back into the directory as a new `.txt` file (with overwrite confirmation prompts).
* **Bilingual UI Interface**: Features a clean English/Chinese dual-language interface for seamless usability.

## 🌟 中文介绍

**ComfyUI-TagPromptPicker** 是一个专为 ComfyUI 设计的轻量级、直观且高效的自定义提示词管理节点。它能让你在本地轻松管理、选择和整理提示词标签，告别繁琐的手动复制粘贴。

### ✨ 核心功能
* **目录自由配置**：通过配置文件持久化保存你专属的标签文件夹路径（`prompt_dir`）。
* **动态标签按钮**：自动扫描并加载指定目录下的所有 `.txt` 文件，渲染为一键点击即可插入的标签按钮。
* **智能拼接去重**：支持自定义分隔符（`delimiter`，如 `, `），在拼接时自动去除多余的前后分隔符，保持提示词整洁。
* **一键整理（Organize）**：自动检测并清除连续重复的分隔符，去除重复的提示词标签。
* **快捷保存与清空**：支持一键清空提示词，或者将当前提示词作为新文件保存回目录中（同名文件覆盖时带有友好的二次确认提示）。
* **双语前台界面**：所有按钮与操作均采用清晰的英文(中文)双语对照显示。
